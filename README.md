# Sillon : versions publiques

Ce dépôt sert seulement à distribuer Sillon : les versions à télécharger (onglet **Releases**) et, plus tard, les mises
à jour automatiques de l'app. Le code de Sillon reste privé.

Aucune version n'est encore publiée.

## Installer une version

Les versions ne sont pas encore signées par Apple ni par Microsoft. Le système affiche donc un avertissement au premier
lancement.

- **Mac** : ouvre l'app une première fois, puis va dans *Réglages système › Confidentialité et sécurité* et clique sur
  « Ouvrir quand même ».
- **Windows** : sur l'écran « Windows a protégé votre ordinateur », clique sur « Informations complémentaires », puis
  sur « Exécuter quand même ».

Sillon utilise Tracktion Engine et JUCE.
